Your sequence.

The Navigator installs in stages. Module 01 is your first move — run it on the schedule below. Modules 02–04 deploy after Module 01 is installed and the read is reflexive.

Module 01 Available

Environmental Read Protocol.

A three-question read for any environment — relational, professional, social. Names what the room is optimizing for, what it is costing, and whose resource is funding it. Surfaces the conscious choice instead of the automatic reaction.

Day 1

Run the Read Protocol on a current room you're stalled in. Save the read.

Days 2–6

Run the protocol on a different room each day. Build the reflex. The 60-second read becomes automatic.

Day 7

Re-read your Day 1 entry. Note what changed — in the architecture, or in your read of it. Module 01 is installed when the read is reflexive.

Module 02 Available

Frequency Classification System.

The Fear / Ego / Attention / Sovereign frequency map. Names the operating frequency of any room you've already read — runs alongside Module 01.

Day 1

Read all four frequency profiles. Run the classifier on the room from your Module 01 Day 1 read. Name the frequency.

Days 2–6

Classify one room per day, in parallel with the Read Protocol. Notice when the same room shifts frequency depending on who is in it or what is at stake.

Day 7

Re-classify the rooms you've been in this week. Module 02 is installed when the frequency registers in seconds, before words form for it.

Module 03 Available

The Three Axioms.

Three load-bearing statements. Read once, operated daily. Each one removes a category of decision so deliberation drops away and the move becomes obvious.

Day 1

Read all three axioms. Sit with what each one removes. Run the daily axiom check at end of day.

Days 2–6

Run the daily check every evening. Each day, pick one axiom and consciously try to apply it once during the day before reflecting at night.

Day 7

Re-read your week of checks. Module 03 is installed when at least one axiom runs without you summoning it.

Module 04 Available

Phase Navigator.

The assessment that names the phase you are operating in right now and the single next move that takes you into the phase above. Run weekly during install, monthly afterward.

Weekly

Monthly

Once Phase 04 is reached, drop to monthly cadence. The Navigator is in maintenance mode — the assessment verifies the perimeter of conscious engagement is holding.
